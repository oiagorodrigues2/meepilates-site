# meepilates-site

Site do Mee Pilates ([meepilates.com.br](https://meepilates.com.br)), em Astro + Tailwind, publicado no Cloudflare Workers (assets estáticos).

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # checagem de tipos + build em dist/
```

Precisa de Node 22.23.4 ou mais novo (veja `.nvmrc`). Regras de trabalho com o Claude em [CLAUDE.md](CLAUDE.md).
